# Сайт «Инвестиции и уровень жизни»

## Запуск у себя
Нужен Python 3.9+ (python.org; на Windows отметьте «Add Python to PATH»).
* Windows: двойной клик по `start.bat`. Mac: `start.command`.
* Или вручную: `pip install -r requirements.txt`, затем `python app.py`.

В окне появится адрес, обычно **http://127.0.0.1:5000** (браузер откроется сам). Адрес `0.0.0.0` в браузере
не работает. Если порт занят, программа возьмёт следующий свободный и напишет его.
Без Python сайт можно открыть двойным кликом по файлу `index.html` (отдельная версия без сервера).

## Что обновляется само
| Данные | Источник |
|---|---|
| Курсы доллара, евро, юаня | Банк России |
| Ключевая ставка и её история на графике | Банк России |
| Индексы МосБиржи и РТС | Московская биржа |

Всё остальное (инфляция, зарплаты, безработица, бедность, инвестиции, регионы, ставки по вкладам
и ипотеке, тексты) нужно менять вручную в начале `app.py` после выхода новых данных Росстата и ЦБ.

## Как работает автообновление
* Сервер (`python app.py`): данные проверяются в фоне раз в 30 минут, страница не ждёт.
* Статический сайт на GitHub Pages: файл `.github/workflows/pages.yml` раз в 6 часов собирает страницу
  заново (`python build_static.py --require-live`) и публикует её. Если ни один источник не ответил,
  сборка падает, а прежняя версия сайта остаётся.

## Включить GitHub Pages с автосборкой
1. Загрузите проект в репозиторий на GitHub.
2. Settings -> Pages -> Source: выберите **GitHub Actions**.
3. Вкладка Actions -> «Обновление сайта» -> Run workflow. Дальше всё идёт по расписанию.

## Календарь решений ЦБ
Раздел «Календарь ЦБ»: восемь заседаний 2026 года, обратный отсчёт до следующего, кнопки «Добавить в Google Календарь» и
«Скачать напоминания (.ics)», у прошедших заседаний показано решение и ссылка на разбор. Даты лежат в `MEETINGS`,
решения в `MEETING_DECISIONS` в `app.py`. После каждого заседания добавьте строку с решением; даты 2027 года внесите, когда ЦБ их опубликует.
Статус заседаний и отсчёт пересчитываются в браузере каждый день, пересборка для этого не нужна.

## Скорость и доступность
* Шрифты подгружаются без блокировки показа страницы, графики ниже экрана рисуются, когда до них доскроллили (перед печатью дорисовываются все).
* Таблица «вилка» сценариев считается, когда браузер свободен, и не перерисовывает графики.
* Есть ссылка «К содержимому» для клавиатуры, область `main`, подписи у всех полей, контраст текста проверен в светлой и тёмной темах.

## Тёмная тема и телефон
Тема выбирается по настройке устройства, а кнопка «Тёмная тема» в шапке переключает её вручную и запоминает выбор.
На экранах уже 640 пикселей таблицы превращаются в карточки (подписи берутся из заголовков столбцов),
для регионов появляется выбор сортировки. В PDF всегда светлая тема.

## Разборы (блог)
Раздел `/razbory/`: короткие статьи про ставки, вклады, инфляцию, ипотеку и налоги, у каждой своя страница
(для поисковиков). Откуда берутся статьи (код в `blog.py`):
* **Автоматические разборы:** каждое изменение ключевой ставки Банка России (история с cbr.ru) превращается в статью с расчётами
  для вклада и ипотеки. Новое решение ЦБ даёт новую статью при следующей сборке сайта, вручную ничего делать не нужно.
* **Постоянные разборы:** четыре статьи, числа в них подставляются из данных сайта (ставка, инфляция, налоговые правила).
* **Новости Банка России:** на странице разборов выводятся заголовки и ссылки из RSS ЦБ.
Автоматические тексты шаблонные и помечены «Автоматический разбор». Свои статьи добавляйте в `guide_posts()` в `blog.py`.

## Накопить на цель и конвертер валют
«Накопить на цель»: сколько откладывать в месяц, чтобы накопить сумму к сроку, с учётом инфляции и уже накопленного.
Конвертер валют (доллар, евро, юань, рубль) берёт официальные курсы Банка России из автообновления; без сети используются
запасные значения из `FX_FALLBACK` в `app.py`.

## Сценарии и ссылка на расчёты
Переключатель «Пессимистичный / Базовый / Оптимистичный» сдвигает ставки по вкладам, облигации, акции, инфляцию, ставки по кредитам
и рост цен на жильё и аренды сразу во всех калькуляторах. Сдвиги заданы в `SCENARIOS` в `app.py` (в процентных пунктах).
Под переключателем таблица «вилка» показывает ключевые результаты при всех трёх сценариях. Значения полей, введённые вручную, сохраняются:
сценарий сдвигает их на выбранную величину. Все ваши значения записываются в адрес страницы (`?s=pess&ln-amount=800000`) и в память
браузера: кнопка «Скопировать ссылку» даёт ссылку для друга, «Сбросить всё» возвращает значения по умолчанию.

## Вклад «на руки», аренда или ипотека, бюджет семьи
В разделе «Налоги, аренда, бюджет и пенсия» три калькулятора: итог по вкладу после налога, капитализации и инфляции;
сравнение капитала владельца и арендатора (меняйте ставку ипотеки, рост цен, доходность вложений);
бюджет семьи с НДФЛ, долговой нагрузкой, подушкой безопасности и накоплениями на год.
Налоговые параметры берутся из `TAX` в `app.py`. Все расчёты ориентировочные.

## Квиз «Проверь себя»
Семь вопросов про ставку, инфляцию и налоги, после ответа показывается пояснение и ссылка на нужный раздел.
Вопросы лежат в `build_quiz()` в `app.py`; про текущую ставку и инфляцию они подставляют актуальные значения.

## Калькулятор кредита
Сумма, срок, ставка, вид платежа (аннуитетный или дифференцированный) и разовая комиссия. Показывает платёж, переплату,
полную стоимость кредита (ПСК) и сравнение с другим видом платежа. Расчёт ориентировочный.

## Налоги и пенсия
Раздел «Налоги и пенсия»: налог на проценты по вкладу, налоговые вычеты (жильё, ипотека, ИИС), калькулятор
пенсии и сравнение вклада, облигаций и акций. Правила налогов лежат в `TAX` в `app.py` (на 2026 год),
примерные доходности облигаций и акций в `BOND_RATE` и `STOCK_RATE`. Проверяйте их после изменений закона.

## PDF-отчёт
Кнопка «Сохранить расчёты в PDF» открывает печать браузера, где нужно выбрать «Сохранить как PDF».
В отчёт попадают все калькуляторы (вклад, ипотека, инфляция, инвестиции, досрочное погашение) с введёнными
вами значениями, сравнение программ ипотеки и графики. Печатная версия всегда светлая.

## Приложение (PWA) и офлайн
Сайт можно установить как приложение (кнопка «Установить» или меню браузера) и открыть без интернета.
Для этого нужен **HTTPS** (GitHub Pages подходит; `localhost` тоже). Файлы: `static/manifest.webmanifest`,
`static/sw.template.js`, `static/icons/`. Версия кэша обновляется при каждой сборке.

## Для поисковиков
В страницу встроены описание, теги для соцсетей, значок вкладки и разметка «Вопросы и ответы».
Для `robots.txt` и `sitemap.xml` нужен адрес сайта: на GitHub Pages он подставляется автоматически,
на своём хостинге задайте переменную `SITE_URL`. После публикации добавьте сайт в Google Search Console
и Яндекс Вебмастер.

`python -m unittest discover tests`

## Безопасность

Подробности в `SECURITY.md` в корне репозитория. Коротко: строгая политика CSP (скрипты только по хэшам), никакого `innerHTML`/`eval`,
защита от встраивания в чужие страницы, проверка данных из внешних источников, заголовки защиты при запуске через Python
(`security.py`), `security.txt`, ограниченные права автосборки и Dependabot. Тесты: `python -m unittest discover -s tests`.
