# Политика безопасности

Сайт статический (GitHub Pages): на сервере нет базы данных, форм, входа и паролей, поэтому красть и взламывать там почти нечего.

## Что сделано
- Политика безопасности контента (CSP): исполняются только скрипты сайта (по хэшам sha256), чужой внедрённый код блокируется.
- В скриптах нет `innerHTML`, `eval` и встроенных обработчиков событий; данные выводятся как текст.
- Защита от встраивания в чужие страницы (clickjacking), `referrer` ограничен, внешние ссылки с `noopener noreferrer`.
- Данные из внешних источников (ЦБ, МосБиржа): только HTTPS, лимит размера, XML без DOCTYPE/ENTITY, в новостях только ссылки на cbr.ru.
- При запуске через Python добавляются заголовки: CSP, X-Frame-Options, nosniff, Permissions-Policy, HSTS (при HTTPS).
- Автосборка: минимальные права, без хранения токена в клонированном репозитории.

## Правила для владельца репозитория
- Включите двухфакторную защиту GitHub (Settings → Password and authentication).
- Никогда не коммитьте токены и пароли; секреты только в Settings → Secrets and variables → Actions.
- Включите защиту ветки main, Dependabot alerts и Secret scanning (Settings → Code security).
